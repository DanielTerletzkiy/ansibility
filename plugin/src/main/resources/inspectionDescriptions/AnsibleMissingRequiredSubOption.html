Reports a dict (or a list item of a list of dicts) that lacks a sub-option its spec marks required. ansible-core fails with missing required arguments whenever the parent value is present.

Example (ANS-T003):

haproxy_servers:
  - name: web1      # no ip, no port

Checked: role defaults/ and vars/ (against the role's own meta/argument_specs.yml), group_vars/host_vars files, inline inventory vars, play, block and task vars:, include_role vars and role parameters, and molecule inventories (against every spec of the same root that declares the variable). Templated values and vault values are not judged here.

The message names the role whose spec is violated and says what the root's target ansible-core would do. When no play of the root applies that role, the message says its spec may be stale. The severity follows the root's Ansibility strictness settings (preset, "Require a reachable play for red"). Suppress a finding with # noinspection AnsibleMissingRequiredSubOption on the line above the key, or with #file: noinspection AnsibleMissingRequiredSubOption.
