Reports required module options that a task does not set (ANS-M002); ansible-core fails the task with missing required arguments: dest (or the action plugin's own message).

An option counts as set when the module mapping, args: or a k=v word gives it under its name or an alias. The free-form pseudo-options of command, raw or meta are not real options. Not reported for templated arguments, for package and service (their backend modules decide), and while any file of the project uses module_defaults, which can supply options.

The quick fix Add option '<name>' adds the option with an empty value.
