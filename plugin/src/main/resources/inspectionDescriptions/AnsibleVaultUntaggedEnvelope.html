Reports YAML values that hold a vault envelope ($ANSIBLE_VAULT;1.1;AES256 and its hex payload) without the !vault tag (ANS-V114). Ansible decrypts only tagged values: an untagged envelope reaches the task, the template or the host as the envelope text.

Quick fix: Add !vault tag writes !vault before the value (key: !vault |). The value itself is not changed; once tagged, the other vault checks judge its envelope. Nothing is decrypted.
