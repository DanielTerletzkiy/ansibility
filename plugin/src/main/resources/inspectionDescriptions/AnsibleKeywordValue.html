Reports play, block, role entry, task, handler, import_playbook and loop_control keyword values that ansible-core rejects when it loads or runs them (ANS-K001), using a port of its keyword validation (FieldAttributeBase and the keyword loaders) for the root's target version:

  • retries: abc, delay: x, become: maybe, loop_control: {pause: x};
  • a list or mapping for a string keyword (become_user: [root]), tags: 5, list items of the wrong type (tags: [1.5], gather_subset: [1]);
  • loader errors: vars that is not a mapping or has invalid names, an invalid register name, a loop_control that is not a literal mapping, task lists that are not lists, empty hosts;
  • play values that fail at run time: serial: [a], an unknown order, an unknown debugger mode.

ansible-core wraps a scalar for a list keyword, so tags: haproxy, notify: Reload haproxy, when: x and serial: 1 are fine. Templated values are not judged.
