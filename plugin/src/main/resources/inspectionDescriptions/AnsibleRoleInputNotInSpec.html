ANS-S002. Reports a variable a role takes from outside that its meta/argument_specs.yml does not declare. ansible-core validates only declared options, and the variable card has no type, description or choices for the others.

Role inputs are the top-level keys of defaults/ and the Jinja uses in tasks, handlers and templates of names nothing inside the role sets (no vars/ key, set_fact, register, task vars:, loop variable, Jinja local, magic variable or fact).

A role without an argument spec gets the same findings as a weak warning, with a fix that creates meta/argument_specs.yml. The fixes infer type (and elements) from the values:

argument_specs:
  main:
    options:
      nginx_port:
        type: int
