ANS-S005. Reports an optional argument_specs option that documents no default: although the role default in defaults/ sets one. Shown without highlighting.

# defaults/main.yml
web_port: 8080

# meta/argument_specs.yml
argument_specs:
  main:
    options:
      web_port:        # ANS-S005: the role default 8080 is not documented
        type: int

The quick fix writes the role default as default:. Required options, secrets (!vault values, vault_* names, vault files, no_log options and dictionaries with a no_log sub-option), templated and null role defaults are left alone. A value written with a YAML alias or anchor is not copied into the spec.
