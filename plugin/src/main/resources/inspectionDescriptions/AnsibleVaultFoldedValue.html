Reports !vault values whose envelope YAML folds or flattens (ANS-V102): a folded block (!vault >) joins the payload lines with spaces, and a plain scalar, or a quoted one whose line breaks YAML folds, delivers the envelope on one line. ansible-vault cannot read either.

db_password: !vault >
  $ANSIBLE_VAULT;1.1;AES256
  6264356538...

Quick fix: Convert to literal block turns > into |, or rewrites a one-line value as a literal block at the indentation the file already uses, with the payload wrapped at 80 columns. It changes the layout only: nothing is decrypted or re-encrypted.
