Reports module option values whose YAML type is not the documented type although ansible-core accepts them by converting them (ANS-T010, T011, T013, T014, T016), or null for an optional option (ANS-T015). For example owner: 1000 where the documentation says str: ansible-core passes '1000' to the module.

Modules receive the converted value by contract, so these findings are not shown by default (decision D5). They appear when the root's Ansibility settings enable Module-option scalar coercions, and as errors under the Strict preset. Every message says what ansible-core does with the value.
